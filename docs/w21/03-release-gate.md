## 変えたこと

### 紹介ページ(W21-01)

- 見本 `landing-mock.html` の構成・文言・色・ホバーをそのまま実装しました。上から、ヘッダー/最初の画面(自動で動く図)/「やることは4つだけ。」/「開始までの流れを試す。」(本物のデモ)/「試した流れを取り入れる。」/最後の段/フッターです。
- ボタン4つ(「▷ ブラウザで試す」「Windows版をダウンロード ⬇」・ヘッダーの「Windows版 ⬇」・最後の札の「最新版をダウンロード(GitHub Releases)」)は、アプリの開始ボタンと同じ動きにしました。乗せると地と枠が明るくなって 1px 浮き、影が付き、字と同じ色の 2px の線が、左右 12px を残して枠の下端いっぱいに伸びます(150ms)。押すと `scale(0.985)`。動きを減らす設定では浮かず縮まず、線は一度に出ます。
- 左端の線:見出し・説明・ボタン・図の中の札と番号・デモの窓・番号1〜6の説明の番号を、すべて同じ文字の列にそろえました。枠のある図(最初の図・4つの段の絵・表)は、枠だけを内側の余白の分だけ外へ出し、中身を列にそろえています。乗せると背景が付く番号の説明は、番号を列にそろえたまま背景を列の外へ出しています。
- デモの段は、台紙や枠をやめてデモの窓だけを置き、下に影を付けました。窓の幅は文字の列いっぱい(1440px の画面で 1120px)です。
- 自動で動く図は 14 秒で繰り返し、乗せると止まります。4つの段の絵は、乗せると見本どおりの動き(差し替え・点滅・線・打ち出し)をします。動きを減らす設定では止まります。
- 書体は、本文が Inter Variable と Noto Sans JP Variable、小見出しと数字の等幅が IBM Plex Mono、05:00 の透かしとロゴが同梱の Bricolage Grotesque です。

### デモのメイン画面(W21-02)

- Windows 版 v1.6.4 の並びに作り直しました。上の帯(ロゴ・検索・WEB DEMO・リセット)、左の列(辞書を開く・開閉できるショートカット・タイマー)、本文(日付と今日の勝利条件が同じ行 → 今やる一手の大きな札 → 今日の3件 → 次の一手 → やりたいこと → 今日の実行)。

- 左下のタイマーは、内側の余白 16px 14px 14px・見出し 17px・分数の表示 42px・− / ＋ と入力欄の高さ 40px(入力欄の字 15px)にしました。動いている間の表示も同じ割合で、左の列からはみ出しません。

### 新しく作った機能(Windows 版と同じ動き)

- **検索**(Ctrl+F):次の一手・やりたいこと・辞書を、このブラウザの中だけで探します。空白のときと見つからないときの案内を出します。
- **計測**:時間を決めずに経過を数え、終えると今日の実行に記録します。今日の3件の未完了の項目で5分以上なら、Windows 版と同じく「今日の分は完了にしますか？」を出します。
- **タイマーの分数の − / ＋**:1〜240分。＋ / − は5分刻み、入力欄はそのままの分数を受け付けます。
- **左の列の開閉**:ショートカットの一覧を開け閉めできます。
- **… のメニュー**:「編集」「今日の3件から外す」「次の一手を編集」「今日の3件に入れる」をメニューへ移しました。画面の端ではメニューが画面の外へ出ないよう内側へ寄せます。
- **鍵の印**:未完了の今日の3件に入っている次の一手は、完了または外すまで元の登録を変えられないことを示します(Windows 版 `sourceEdit.ts` と同じ規則)。

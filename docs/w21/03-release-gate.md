## 本番反映の手順(Claude Code が行う)

オーナーは PR の画面とスクリーンショットを見て「マージして」と伝えます。そのあとは Claude Code が行います。

1. PR #25 の CI が通っていることを確かめる。
2. 「Create a merge commit」で `main` にマージする(squash しない)。Cloudflare の Git 連携が自動でビルドして本番に反映する。
3. ビルドが終わったら、本番を Windows のブラウザで、1440 と 390 の幅で確かめる。見る所は最初の画面・自動で動く図・4つのボタンのホバー・デモの窓(今日の3件が1行に3つ、計測のボタン、次の一手の行、閉じた「やりたいこと」)・「試した流れを取り入れる。」・最後の段。コンソールエラーが無いことも確かめる。
4. 問題があれば、`main` のこのマージを revert し、理由を報告して止まる(同じ Git 連携で一つ前の版に戻る)。
5. 問題が無ければ、Windows 版リポジトリ(Takuyakou/life-launcher)の README の `docs/screenshots/web-demo.png` を、本番の 1440×900 の最初の画面で差し替える。`docs/screenshots/README.md` の説明も W21 のものに直す。ブランチ `docs/web-demo-w21-image` で PR を作り、「Create a merge commit」でマージする。リリースはしない。

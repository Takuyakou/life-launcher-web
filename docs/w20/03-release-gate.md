## 変えたこと

- W19 では、最後の段の札(Windows版を入手)は幅 460px で右端に寄せていたため、左端がすぐ上の安全性の段の一覧(「Windows版のユーザーデータは…」)の左端より右にずれていた。
- 最後の段を、安全性の段と同じ2列の格子(各列 1fr、間 72px、1列になる幅も同じ)にした。見出しと文字のリンクは左の列、札は右の列の左端に置く。これで札の左端が一覧の左端に、見出しの左端が「Local-first.」の左端にそろう。札の幅は 460px のまま(右端はそろえない)。
- 札の下端と「まずはブラウザで試す」の行の下端は、これまでどおりそろえる。
- 見出しを「次の一手を、」と「今ここで始める。」の2つのかたまりに分け、2列になる幅(1032px 以上)では必ずこの2行にする。W19 の本番確認で、Windows の書体では 1366px のとき見出しが1行に収まっていた(字が 46.4px で文字の幅 543px、枠 560px)。列の幅に任せると書体と画面の幅で行数が変わるため、かたまりごとに1行ずつ置く形にした。1列になる幅では、折り返すときはかたまりの間(「、」の後)だけで折り返す(390px でも「次の一手を、/今ここで始める。」)。見出しの読み上げの名前は、かたまりの間に空白が入ることがある。
- 1列になる幅(安全性の段も1列になる)では、札は見出しの下で左端をそろえる(幅 460px)。スマホ(600px 以下)では横いっぱい。

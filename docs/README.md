# Life Launcher Web Docs

このディレクトリは、Life Launcher Web Demo固有の仕様・設計判断・検証記録を置く場所です。

- リリース版の仕様は [Life Launcher本体](https://github.com/Takuyakou/life-launcher) を参照してください。
- Web Demoは、Windows固有機能を実行せず、開始までの体験をブラウザ上で再現します。
- Projectの次の一手とやりたいことを登録し、Today Pickerで今日の3件を選び、タイマーから実行する中心フローを扱います。
- 今後Web DemoのUIや挙動を変更するPRでは、必要に応じてこの配下の文書も更新します。

## v1.4 で合わせたこと・合わせなかったこと

Windows版 v1.4.0 / v1.4.1(タグ `v1.4.1`)のうち、Web Demoにある部品だけを合わせています。画面の完全な一致は目指していません。

合わせたこと:

- 今やる一手は、今日の3件に入っている未完了の一手を先に表示し、「他の一手」で選んだものはプロジェクトIDで保ちます。今やる一手と今日の3件は同じタイマーの状態を表示します。
- 今日の3件の見出しの件数は「完了数 / 件数 完了」か「0件」だけ。次の一手のボタンとダイアログは「編集」。
- 色の役割(追加は中立色、保存・決定は緑、キャンセル・終了は赤、実行中は緑、黄色は今日の3件の入口・勝利条件・フォーカス)、枠の役割(見出し・カード・点線の入口に枠、区切り線とテキストボタンは枠なし)、4つの見出しの並びと件数の位置、フォーカスの輪が1つ、勝利条件の光り方(未入力も枠だけ反応)。
- 保存形式(`life-launcher-web-demo:v3`、`schemaVersion: 3`)は変えていません。

合わせなかったこと(Web Demoの範囲外): 表示サイズ(大・特大)、ミニタイマー、拡大タイマー、サイドバーの待機中Timer、設定画面、記録画面、空グループの案内、今週の重点など今やる一手の残りの並び順、タイマーの開始・一時停止の通知の廃止。

## 今やる一手の並び順

今日の3件に未完了で入っている次の一手を先に(複数なら今日の3件の順)、ほかは登録順で表示します。理由は、今日の3件のものが「今日の3件に入っている一手です」、ほかは固定の文言です。「他の一手」で選んだものはプロジェクトIDで画面の状態としてだけ覚え、localStorageには保存しません。

今やる一手から開始すると、そのプロジェクトの次の一手が今日の3件に未完了で1件だけあるときに、その項目とタイマーをつなげます。今日の3件のカードと今やる一手には同じタイマーの状態が出て、満了の確定で今日の3件の項目だけが完了になります。

## 今日の3件から外す

カード左下の「今日の3件から外す」で、Today3への採用だけを解除できます。確認ダイアログはなく、保存成功後に短い通知を表示します。次の一手・やりたいこと・Today Picker候補・実行記録は残ります。

対象カードのタイマー実行中・一時停止中・満了確認待ちは解除不可です。別のカードのタイマーには影響しません。完了済みカードも解除できますが、完了記録は残り、次のバッチを選ぶ条件は従来どおり現在の3件すべての完了です。

localStorageの保存に失敗した場合は表示も変更せず、元の順序とsnapshotを維持します。Web DemoにはD&Dは実装していません。

## 予定より早く終了する

予定より早く終わった場合でも、短時間以上取り組んでいれば今日の完了を選べます。

- 未完了のToday3に対応するタイマーを手動終了したときだけ確認します。基準は採用済みsnapshotの短時間分数と5分の小さい方です。整数1〜240以外・欠損は5分に戻します。
- 経過秒が基準以上、かつ予定時間未満の場合に表示します。基準への到達だけでは完了せず、予定時間の満了は従来の終了画面を優先します。
- 左が「今日の分は完了」、右が「未完了のまま終了」。初期フォーカス・Escapeは右です。背景クリックでは閉じません。確認中は時間を進めません。
- 完了はToday3だけに反映します。元の次の一手・やりたいこと・候補は残り、どちらを選んでも実行記録を保存します。部分補充はしません。
- 確認中の対象カードは解除できません。localStorageへの一括保存が失敗すると確認画面と変更前のToday3・Sessionを保持し、再試行できます。
- 「短時間分まで進める」はDemo用の時間短縮操作です。通常25分で開始すると基準まで進めて早期終了を試せます。seedの短時間は既存の5分を維持し、3分snapshotも自動テストします。
- Project設定UIやNativeとの完全互換は対象外です。既存Demoの実行記録は切り上げ・最低1分であり、本体の切り捨て・1分未満は記録なしとは異なります。タイマー自体は再読み込み時に待機へ戻ります。

## 最初の画面の手直し

- ボタンの下の GitHub の文字のリンクを外した(ヘッダーとフッターには残る)。
- 左右2列で並ぶ幅(1064px 以上)では、右の段(候補の札と今やる一手のカード)を、下端が左のボタンとそろう位置から 22px 下げた所に置く(カードの下端がボタンの下端より 22px 下)。

## 開始ボタンのホバー(Windows版 v1.6.3 から写した)

最初の画面のカードと、デモの中の開始ボタン(今やる一手・今日の3件)にかける。乗せると地と枠が明るくなり、1px 浮いて影が付き、下に 2px の線が真ん中から伸びる(色・浮きは 130ms、線は 150ms)。押すと `scale(0.985)` で少し縮む。動きを減らす設定の時は浮かず縮まない。ボタンのふだんの色は変えていない。

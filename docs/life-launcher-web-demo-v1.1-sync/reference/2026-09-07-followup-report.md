## 1. ダッシュボード操作の調整

- 共通確認ダイアログのボタン順を、左に確定操作（削除・完了にする等）、右にキャンセルへ変更した。初期フォーカスはキャンセルを維持した。
- 「今日を組み立てる」「次の一手」「やりたいこと」「今日の実行」は、左のラベルだけでなく、件数・補足・余白を含むバー全体で開閉できるようにした。
- バー内の追加ボタン等は開閉処理の対象外とし、既存の操作を維持した。
- 次の一手の右クリックメニューへ「今日へ」を追加した。既存の採用処理を再利用し、3件上限・同じsourceの重複判定・採用時の分数や手順書等のsnapshotを維持した。
- 常設の「今日へ」ボタンは増やさず、現行仕様書とアプリ内ガイドへ右クリック経路を反映した。

## 2. 辞書の複数ディスプレイ対応

- 辞書を開く際、呼び出し元であるメインウィンドウの現在モニターを取得するようにした。新規作成と既存辞書の再表示に共通で適用する。
- 辞書の中心が対象モニターの作業領域内なら、前回位置を維持しつつ端からのはみ出しを補正する。
- 別モニターまたは画面外にある場合は、対象モニターの中央へ配置する。
- 作業領域と16pxの安全余白を使って位置・サイズを補正する。負座標のディスプレイにも対応する。
- 現在モニターを取得できない場合は、プライマリ、利用可能な先頭モニターの順で代替する。
- `core:window:default`に`allow-current-monitor`が含まれることを確認した。権限追加は行っていない。

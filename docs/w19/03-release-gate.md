## 変えたこと

### 最後の段

- 広い幅(1366 / 1440 / 1920 で確認)では、見出しと文字のリンクを左、Windows 版の札を右に置き、札の下端を文字のリンクの下端とそろえる。見出しは「次の一手を、/今ここで始める。」の2行で折り返す(字の大きさは他の段と同じ)。
- 1000px 前後より狭い幅では、札は見出しの下に回る(1000px で確認)。スマホ(600px 以下)では縦に並べ、間は 24px。
- 札の見出しと金色のボタンの字の太さを 800 から 700 にした。800 だと Windows では英字(Segoe UI)だけが極太になり、700 までしかない日本語(Yu Gothic UI)と太さが混ざっていた。

### 小さなダイアログの形(確認・予定時間・次の一手・やりたいこと)

- Windows 版と同じく、左に決定・右にキャンセルで横いっぱいを等分する(右寄せの小さなボタンをやめた)。
- 壊す操作の確認(破棄・リセット)は、決定が赤、戻る側が灰色(Windows 版と同じ)。決定が緑の確認(今日の分は完了)は、もう一方が赤のまま。

## 本番反映の手順(オーナーが行う)

1. このブランチの CI が通っていることを確かめる。
2. 「Create a merge commit」で `main` にマージする(squash しない)。Cloudflare の Git 連携が自動でビルドして本番に反映する。
3. 公開 URL で、次の点を確かめる。
   - 1440px 前後の幅で、最後の段の見出しが2行・札が右にあり、札の下端が「まずはブラウザで試す」の行とそろう。札の「Windows」と「版を入手」、ボタンの英字と日本語の太さがそろって見える。
   - デモで「今日の3件」の空き枠の「＋ 今日やるものを選ぶ」を押し、何か1つ「＋ 今日へ」で選んでから「キャンセル」を押す。破棄の確認で、左が赤い「破棄する」、右が灰色の「編集を続ける」、どちらも半分ずつの幅になっている。
   - タイマーを始めると「一時停止」が緑になる。

戻し方: 公開 URL での確認で問題があれば、`main` のこのマージを revert する(同じ Git 連携で一つ前の版に戻る)。

## 実装内容の要約

- 4つのセクション見出しを、枠付きの「名前 → 件数 → 説明」に統一した。件数の左端を縦にそろえ(「やりたいこと」の右端から 18px)、説明・名前の文字をそろえた。

## 判断メモ

- 見出しの hover は、Windows 版 §4.2 が見出しを共通 hover(浮く・影)の対象外としているので、浮かせず背景と枠だけにした。以前の Web Demo は浮いていた。
- 「今日の3件から外す」は枠を透明にしても、既存の `interaction-grammar.spec.ts`(hover で浮く・影が出る)が通るよう、浮きと影は残した。
- 次の一手は Windows 版の 3/2/1 列のカードにはせず、1列の枠付きカードにした(行の中の操作が横に並ぶ今の作りを保つため)。
- 「保存して終わる」は緑にしたが、同じ画面の「終わる」は中立のままにした。「終わる」を決定(緑)とみなすかは判断が分かれるので、提案に書く。
- 入口の点線の枠は、カード 1〜2 件のときは並びの空き枠、0 件のときは全幅。空の状態の案内文は足していない(範囲外)。
- `:has()` を使っている(「やりたいこと」の囲みの輪)。対象の Chromium は対応している。
